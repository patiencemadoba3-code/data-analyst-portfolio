# FRIEND App Project
**Tools & Skills**: App design, problem solving, health focused tech, planning
**Context**: Developed as a finalist in the innovateHER 2025 cohort

FRIEND is a wellness and support app idea I created to help people track and manage their mental and physical health in one simple place.
- Designed the core concept and features to match real user needs
- Planned how data will be collected, organised and kept secure
- Built this idea to combine my background in biology/health with technology
- This project is what inspired me to learn SQL, cloud and data skills to make it a fully working app one day

It shows how I think about using tech to solve real problems that matter to people.
