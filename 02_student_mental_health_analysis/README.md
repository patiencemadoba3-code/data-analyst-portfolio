# Student Mental Health Analysis
**Tools**: PostgreSQL / SQL

I explored survey data to investigate whether international students face higher mental health risks, and if length of stay affects their wellbeing.
- Cleaned and organised survey records
- Used joins, filters and aggregations to compare groups
- Analysed patterns for social connectedness and acculturative stress
- Confirmed key trends matching the original study findings

This project shows how data can be used to understand real human needs linking my science background with data analysis skills.
