# Hotel Operations Analysis
**Tools**: SQL
**Context**: Practical Exam for SQL Associate Certification

Analysed service performance for LuxurStay Hotels to identify causes of slow service and low customer satisfaction.
- Cleaned and validated branch data; fixed missing values, corrected formats, applied business rules
- Calculated average and maximum response times per service and branch
- Joined tables to extract data for targeted regions and services (Meal, Laundry in EMEA & LATAM)
- Identified all service branch combinations with average ratings below the 4.5 target
- Used filtering, grouping, joins, aggregation and conditional logic to deliver actionable insights

This project shows how I use SQL to turn raw data into clear answers that help improve business performance.
