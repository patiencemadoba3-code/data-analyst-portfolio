# Grocery Store Sales Analysis
**Tools**: SQL
**Context**: Practical Exam for Data Analyst Associate Certification

Analysed product data for FoodYum grocery chain to support stock planning and pricing decisions.
- Counted and identified missing values in the dataset
- Fully cleaned the data: replaced missing values with medians/defaults, fixed formats, standardised text
- Calculated price ranges (min/max) for every product category
- Filtered to find high-volume Meat & Dairy products
- Used aggregation, filtering, and conditional logic to deliver business-ready insights

This project demonstrates full data workflow skills: inspect → clean → analyse → answer business questions.
